# Анализатор эмоционального сходства перевода

Небольшое веб-приложение, которое анализирует эмоциональное сходство между оригинальным текстом и его переводом на английском языке в рамках литературных произведений. Система сравнивает эмоциональные характеристики двух фрагментов текста и показывает, насколько перевод сохраняет эмоциональный тон оригинала. Кроме того, система выделяет культурные маркеры, которые могут создавать неточности при переводе. Благодаря им производит адаптация анализа под культурные особенности англоговорящих стран.

Проект реализован на Python и Flask с веб-интерфейсом на HTML/CSS и использует простой NLP-подход для анализа эмоций. Также представлен датасет культурных маркеров для выявления потенциально проблемных элементов перевода.

# Возможности

- Сравнение двух текстовых фрагментов: оригинала и перевода
- Определение доминирующей эмоции каждого текста (положительная, отрицательная, нейтральная)
- Расчёт процента эмоционального сходства между текстами
- Анализ эмоциональных метрик:
  - Количество положительных и отрицательных слов
  - Эмоциональная плотность
  - Полярность текста
  - Баланс эмоций
  - Слова-усилители (интенсификаторы)
- Выявление культурных маркеров в тексте из загружаемого датасета
- Оценка риска искажения эмоционального фона при переводе из-за культурных маркеров
- Автоматическая рекомендация для переводчика при обнаружении проблемных элементов
- Визуализация результатов в виде прогресс-бара и цветовых индикаторов риска
- Быстрый запуск локально

Для расчёта общего сходства используется метод cosine similarity.

# Установка

1) Клонируйте репозиторий

2) Создайте виртуальное окружение:

python -m venv .venv

3) Активируйте окружение:

Windows:
.venv\Scripts\activate

Mac / Linux:

source .venv/bin/activate

4) Установите зависимости:

pip install flask


# Запуск приложения

1) Запустите сервер Flask:

python app.py

2) Откройте в браузере:

http://127.0.0.1:5000

# Использование

Данное веб-приложение работает на литературных произведениях, загрузите часть проивзедения, которую хотите проверить и смотрите результаты!

Для удобства тестирования данного приложения в структуре представлены книги "1983" и "Гарри Поттер и философский камень", можете использовать отрывки из них.
P.S. Культурные маркеры частично собирались именно по этим книгам, поэтому будет удобно посмотреть работу именно на них.
